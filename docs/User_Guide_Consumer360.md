# User Guide (How to Run) --- Consumer360 Retail Analytics

## Prerequisites

Before running the Consumer360 Retail Analytics project, make sure the
following software is installed:

-   PostgreSQL installed and running
-   Python 3.x installed
-   Power BI Desktop installed

These tools are required to run the analytics pipeline and visualize
results in the Power BI dashboard.

------------------------------------------------------------------------

## Step 1: Configure Database

Update the database credentials in:

`python/config.py`

Example configuration:

``` python
DB_CONFIG = {
  "user": "postgres",
  "password": "YOUR_PASSWORD",
  "host": "localhost",
  "port": "5432",
  "database": "consumer360_db"
}
```

Ensure PostgreSQL is running and the database is created before
executing the pipeline.

------------------------------------------------------------------------

## Step 2: Install Dependencies

Open a terminal in the **project root directory** and run:

    pip install pandas sqlalchemy psycopg2

These libraries are used for:

-   connecting to PostgreSQL
-   processing retail transaction data
-   generating analytics outputs used in Power BI

------------------------------------------------------------------------

## Step 3: Run Full Analytics Pipeline

From the project root:

    cd python
    python run_pipeline.py

This pipeline automatically runs the full analytics workflow including:

-   RFM customer segmentation
-   Cohort retention analysis
-   Customer Lifetime Value (CLV proxy) scoring
-   Market basket product pair analysis

------------------------------------------------------------------------

## Generated Output Files

After the pipeline runs, the following files are created or updated
inside the `/data` folder:

    rfm_results.csv
    clv_results.csv
    cohort_retention.csv
    market_basket_results.csv

These files act as **data sources for the Power BI dashboard**.

------------------------------------------------------------------------

## Step 4: Refresh Power BI Dashboard

Open the Power BI dashboard file:

    reports/Rfm Analysis.pbix

Then:

1.  Go to **Home**
2.  Click **Refresh All**

The dashboard will automatically update using the latest analytics
outputs generated by the pipeline.

------------------------------------------------------------------------

## Project Summary

Consumer360 Retail Analytics automates the full analytics workflow:

1.  Retail transaction data is stored in PostgreSQL.
2.  Python scripts perform analytics such as RFM segmentation, cohort
    analysis, CLV scoring, and market basket analysis.
3.  The pipeline generates CSV outputs used by Power BI.
4.  Power BI dashboards visualize the results for business insights.

This workflow enables retail businesses to analyze customer behavior and
make data‑driven decisions.
