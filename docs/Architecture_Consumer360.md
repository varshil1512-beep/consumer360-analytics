# Architecture (End-to-End Flow)

## Data Flow

The Consumer360 Retail Analytics system processes retail transaction
data through a structured analytics pipeline that converts raw data into
business insights.

Pipeline flow:

1.  Raw retail transaction dataset
2.  PostgreSQL staging and star schema
3.  Python analytics pipeline
4.  Analytical outputs generated as CSV
5.  Power BI dashboards refresh using the generated outputs

This pipeline allows automated analytics generation and dashboard
updates.

------------------------------------------------------------------------

## PostgreSQL Data Warehouse

The system uses PostgreSQL as the main data warehouse.

Schema: `retail`

Main tables include:

### Staging Table

`stg_orders`\
Stores the raw retail transaction dataset before transformation.

### Fact Table

`fact_sales`\
Contains transaction-level sales data including product, quantity,
price, and date.

### Dimension Tables

`dim_customer`\
Stores customer-level information.

`dim_product`\
Stores product attributes.

`dim_date`\
Stores date attributes for time-based analytics.

The star schema design enables efficient analytical queries.

------------------------------------------------------------------------

## Python Analytics Layer

Python scripts perform the core analytics operations.

Main scripts include:

`data_loader.py` -- extracts aggregated customer-level data from
PostgreSQL.

`rfm_analysis.py` -- calculates Recency, Frequency, and Monetary values
and assigns RFM segments.

`cohort_analysis.py` -- generates retention cohorts and cohort matrices.

`clv_generate.py` -- calculates a Customer Lifetime Value proxy score
used to rank customers.

`market_basket.py` -- identifies frequently purchased product pairs for
cross-selling insights.

`run_pipeline.py` -- executes the entire analytics pipeline and
generates outputs.

------------------------------------------------------------------------

## Output Files (Power BI Inputs)

The pipeline generates analytics outputs stored in the `/data`
directory.

Generated files:

rfm_results.csv\
clv_results.csv\
cohort_retention.csv\
market_basket_results.csv

These files act as data sources for the Power BI dashboard.

------------------------------------------------------------------------

## Power BI Dashboard

Power BI is used to visualize insights generated by the analytics
pipeline.

Dashboard pages include:

Page 1 -- RFM Executive Overview\
Shows customer segmentation and revenue distribution.

Page 2 -- Cohort Retention Analysis\
Displays retention trends across cohorts.

Page 3 -- Strategic Customer Intelligence\
Shows CLV ranking and cross‑sell insights.
